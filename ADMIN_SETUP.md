# Панель внесения изменений — настройка и обновление

Публичная оболочка панели находится по адресу:

`https://sosh20tver.ru/admin-changes.html`

Панель работает через Google Apps Script и записывает изменения в школьную Google Таблицу.

## Первый запуск

1. Откройте `https://script.google.com/` под Google-аккаунтом, у которого есть право редактировать школьную таблицу.
2. Создайте новый проект, например `СОШ 20 — панель изменений`.
3. В `Code.gs` вставьте содержимое `apps-script/Code.gs` из этого репозитория.
4. Создайте HTML-файл `Admin` и вставьте содержимое `apps-script/Admin.html`.
5. Создайте ещё один файл скрипта **`PublishWarnings.gs`** и вставьте содержимое `apps-script/PublishWarnings.gs`.

## Свойства скрипта

В **Настройки проекта → Свойства скрипта** добавьте:

- `SPREADSHEET_ID` = `1Va5atMLtrqb9JEXE7d9eytoTUFgN-lwT0xlYOevm4S4`
- `ADMIN_PIN` = ваш PIN администратора.

## Развертывание

1. **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: **Я**.
4. Доступ: **Все** либо максимально широкий вариант, разрешённый вашим Google Workspace.
5. Подтвердите разрешения и скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
6. Один раз вставьте этот адрес на странице `https://sosh20tver.ru/admin-changes.html`.

## Если панель уже была развернута

После текущего обновления нужно сделать один раз:

1. Заменить `Code.gs` актуальной версией из репозитория, если он у вас старый.
2. Заменить `Admin.html` актуальной версией.
3. Создать `PublishWarnings.gs`, если его ещё нет, и вставить соответствующий файл из репозитория.
4. **Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть**.

URL и PIN при этом не меняются.

## Как теперь работает проверка конфликтов

Проверка кабинетов, классов, предметов и других потенциальных ошибок сохранена. Однако она теперь **информационная**:

- панель показывает список возможных конфликтов;
- вы можете закрыть предупреждение;
- публикация после этого продолжается;
- предупреждения сохраняются в результате публикации и не блокируют вашу работу.

Это сделано специально для ситуаций, когда один кабинет допустимо использовать параллельно либо система не знает особенности конкретного урока.

## Ежедневная работа

1. Откройте `https://sosh20tver.ru/admin-changes.html`.
2. Введите PIN.
3. Выберите дату.
4. В сетке учителей щёлкните нужную клетку.
5. Можно **зачеркнуть** исходный урок либо поставить другой класс, предмет и кабинет.
6. На вкладке **«Список для учеников»** проверьте, что автоматически сформировалось для классов.
7. Нажмите **«Опубликовать изменения»**.

После публикации одновременно обновляются ученические изменения и сетка для учителей.

## Страница для учителей

Учительская сетка доступна прямо с основного школьного сайта:

`https://sosh20tver.ru/staff.html`

Ссылка **«Учителям» / «Расписание для учителей»** добавлена в основную навигацию и на главную страницу.

На компьютере отображается полная сетка `учитель × уроки 1–12`. На телефоне — карточки выбранного преподавателя.

## Обозначения

- белая клетка — основное расписание;
- красная/перечёркнутая — отмена, окно;
- голубая — замена;
- жёлтая — смена кабинета;
- зелёная — дополнительный урок.

## Горячие клавиши в админ-панели

- `X` — зачеркнуть выбранную клетку;
- `Delete` / `Backspace` — вернуть исходное состояние;
- `Enter` — открыть редактирование выбранной клетки.

## Технические листы Google Таблицы

- `Изменения` — то, что видят ученики;
- `Учителя` — основная учительская сетка;
- `Изменения_учителей` — ваши изменения по клеткам;
- `Учителя_сайт` — опубликованная сетка для страницы сотрудников;
- `История_публикаций` — техническая история публикаций и откатов.
