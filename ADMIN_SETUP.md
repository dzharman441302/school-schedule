# Панель внесения изменений — первичная настройка

Публичная часть панели уже находится на сайте по адресу:

`https://sosh20tver.ru/admin-changes.html`

Для безопасной записи в Google Таблицу требуется один раз развернуть Google Apps Script. После этого ежедневная работа выполняется только через панель.

## 1. Создать Apps Script

1. Откройте `https://script.google.com/` под Google-аккаунтом, у которого есть право редактировать школьную таблицу.
2. Нажмите **Новый проект**.
3. Назовите его, например: `СОШ 20 — панель изменений`.
4. В файле `Code.gs` удалите исходный код и вставьте содержимое файла `apps-script/Code.gs` из этого репозитория.
5. Нажмите **+** рядом с «Файлы» → **HTML** → имя файла `Admin`.
6. Вставьте в него содержимое `apps-script/Admin.html`.

## 2. Указать таблицу и PIN

1. В Apps Script откройте **Настройки проекта**.
2. Найдите **Свойства скрипта**.
3. Добавьте:
   - `SPREADSHEET_ID` = `1Va5atMLtrqb9JEXE7d9eytoTUFgN-lwT0xlYOevm4S4`
   - `ADMIN_PIN` = придуманный вами PIN, например 6–8 цифр.

PIN хранится только на стороне Apps Script и не публикуется в коде школьного сайта.

## 3. Развернуть веб-приложение

1. Нажмите **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: **Я**.
4. Кто имеет доступ: **Все**. Если в вашем аккаунте вариант «Все» недоступен, выберите максимально широкий доступ, разрешённый организацией.
5. Нажмите **Развернуть** и подтвердите разрешения Google.
6. Скопируйте URL вида:
   `https://script.google.com/macros/s/XXXXXXXXXXXX/exec`

## 4. Подключить к сайту

1. Откройте `https://sosh20tver.ru/admin-changes.html`.
2. Вставьте URL веб-приложения Apps Script.
3. Нажмите **Подключить**.
4. Адрес сохранится в этом браузере. На другом компьютере/телефоне его нужно вставить один раз снова.

## Ежедневная работа

1. Откройте `https://sosh20tver.ru/admin-changes.html`.
2. Введите PIN.
3. Выберите дату и класс.
4. Панель покажет основное расписание выбранного класса.
5. Для отмены нажмите **Отмена** напротив урока.
6. Для замены нажмите **Изменить**, введите новый предмет/текст и при необходимости примечание или кабинет.
7. Повторите для остальных классов. Все изменения выбранной даты собираются справа в общий список.
8. Нажмите **Опубликовать изменения** один раз.

Панель заменяет все строки выбранной даты в листе `Изменения` на текущий список панели. Поэтому перед публикацией она сначала загружает уже существующие изменения за эту дату и позволяет их отредактировать, не теряя внесённые ранее записи.

## Дополнительные функции

- Кнопки **Сегодня** и **Завтра**.
- Автоподстановка основного расписания.
- Для 7–8 классов выводятся уроки 4–12.
- Для остальных классов — 1–8, плюс любые дополнительные уроки, которые есть в расписании или изменениях.
- Быстрая кнопка **Отмена**.
- Свободный текст замены с подсказками предметов.
- Примечание/кабинет отдельным полем.
- Общий список изменений дня.
- Удаление отдельной записи.
- Очистка всего дня.
- Защита от случайного ухода со страницы при неопубликованных изменениях.
- Сессия после ввода PIN действует до 6 часов и продлевается при работе.

## Если нужно изменить PIN

Измените значение `ADMIN_PIN` в **Настройки проекта → Свойства скрипта**. Повторное развертывание для этого не требуется.

## Если менялся код Apps Script

После изменения `Code.gs` или `Admin.html`:

1. **Развернуть → Управление развертываниями**.
2. Выберите текущее веб-приложение.
3. Нажмите **Изменить**.
4. Создайте **новую версию** и сохраните развертывание.

URL веб-приложения останется прежним.
