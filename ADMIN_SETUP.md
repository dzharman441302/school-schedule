# Панель замен и учительская сетка — настройка

Публичные страницы:

- админ-панель: `https://sosh20tver.ru/admin-changes.html`
- сетка для учителей: `https://sosh20tver.ru/staff.html`
- ученическое расписание и изменения: `https://sosh20tver.ru/schedule.html`

Админ-панель работает через Google Apps Script. Учительская страница читает только уже опубликованные данные из Google Таблицы.

## Если Apps Script уже был развернут

После этого обновления нужно один раз обновить код развертывания:

1. Откройте ваш существующий проект Apps Script.
2. Полностью замените содержимое `Code.gs` кодом из `apps-script/Code.gs` этого репозитория.
3. Полностью замените содержимое `Admin.html` кодом из `apps-script/Admin.html`.
4. Нажмите **Развернуть → Управление развертываниями**.
5. Выберите текущее веб-приложение → **Изменить**.
6. В поле версии выберите **Новая версия**.
7. Нажмите **Развернуть**.

URL веб-приложения останется прежним, поэтому `admin-changes.html` заново подключать не потребуется.

3. В `Code.gs` вставьте содержимое `apps-script/Code.gs`.
4. Создайте HTML-файл с именем `Admin` и вставьте содержимое `apps-script/Admin.html`.

## Как теперь устроена работа

### 1. Вы вносите изменения в сетку учителей

Основной режим панели — **Сетка учителей**.

- строка = учитель;
- столбец = урок 1–12;
- `X` — зачеркнуть исходный урок;
- `Delete` — вернуть исходную клетку;
- `Enter` — открыть редактирование;
- можно поставить другой класс, предмет и кабинет;
- можно включить **Только изменённые строки**;
- есть масштабирование сетки.

### 2. Панель сама формирует изменения для учеников

Пример:

- у одного учителя снят `7Б · История · 205`;
- у другого учителя поставлен `7Б · География · 301`.

В ученический список автоматически попадёт:

`7Б · 7 урок — География (301)`

Если поменялся только учитель, а предмет и кабинет у класса остались теми же, отдельная запись для учеников не создаётся.

Если класс снят и больше никуда не поставлен, формируется `отмена`.

### 3. Проверка перед публикацией

В панели есть кнопка **Проверить конфликты**. Перед каждой публикацией эта проверка запускается автоматически.

Проверяются:

- один цифровой кабинет у двух учителей одновременно;
- лишнее одновременное назначение одного класса сверх исходного деления на группы;
- новый урок без класса;
- новый урок без предмета;
- неизвестный учитель;
- предупреждение при отсутствии кабинета там, где он обычно нужен.

При критической ошибке публикация блокируется.

### 4. Публикация

Кнопка **Опубликовать изменения** одновременно обновляет:

- лист `Изменения` — то, что увидят ученики;
- лист `Изменения_учителей` — технические изменения сетки;
- лист `Учителя_сайт` — полную опубликованную сетку для учителей;
- `История_публикаций` — снимок состояния для возможного отката.

### 5. Учительская страница

Адрес:

`https://sosh20tver.ru/staff.html`

На компьютере показывается полная сетка:

- белая клетка — без изменений;
- красная и зачёркнутая — урок снят, появляется `ОКНО`;
- голубая — замена;
- жёлтая — изменён только кабинет;
- зелёная — добавлен новый урок.

Если система однозначно видит перенос класса от одного учителя к другому, в клетках появляется стрелка с фамилией преподавателя.

Есть:

- выбор даты;
- Сегодня / Завтра;
- поиск учителя;
- режим **Только изменённые учителя**;
- обновление данных;
- печать полной сетки.

На телефоне вместо широкой таблицы автоматически включаются карточки выбранного учителя с фильтром **Только изменённые уроки**.

Страница имеет `noindex` и не добавлена в основное публичное меню сайта. Ссылка на неё есть из админ-панели.

## История и откат

В админ-панели есть кнопка **История**.

Хранятся последние публикации. Кнопка **Откатить** возвращает состояние выбранной даты к тому, которое было до указанной публикации. Текущее состояние перед откатом также сохраняется в истории.

## Печать

Кнопка **Печать замен** в админ-панели формирует компактный лист изменений для учителей и учеников.

Кнопка **Печать** на `staff.html` печатает актуальную учительскую сетку.

## Важно

После изменения `Code.gs` или `Admin.html` всегда создавайте **новую версию** существующего развертывания Apps Script. Простого сохранения кода недостаточно: старое развертывание продолжит выполнять старую версию.
