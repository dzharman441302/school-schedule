# Панель замен — настройка и работа

Панель открывается по адресу:

`https://sosh20tver.ru/admin-changes.html`

Основной режим теперь повторяет бумажную учительскую сетку: выбираете дату, видите всех учителей и уроки 1–12, зачёркиваете старое назначение и ставите новый класс прямо в клетке. Список изменений для учеников формируется автоматически.

## 1. Первичная настройка Apps Script

Если Apps Script ещё не создан:

1. Откройте `https://script.google.com/` под Google-аккаунтом, у которого есть право редактировать школьную таблицу.
2. Нажмите **Новый проект**.
3. Назовите его, например `СОШ 20 — панель замен`.
4. В `Code.gs` вставьте содержимое `apps-script/Code.gs` из этого репозитория.
5. Нажмите **+ → HTML**, создайте файл `Admin`.
6. Вставьте в него содержимое `apps-script/Admin.html`.

### Свойства скрипта

В **Настройки проекта → Свойства скрипта** добавьте:

- `SPREADSHEET_ID` = `1Va5atMLtrqb9JEXE7d9eytoTUFgN-lwT0xlYOevm4S4`
- `ADMIN_PIN` = ваш PIN, желательно 6–8 цифр или длиннее.

PIN остаётся только в Apps Script и не попадает в публичный код сайта.

## 2. Развертывание

1. **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: **Я**.
4. Кто имеет доступ: **Все** или максимально широкий вариант, разрешённый аккаунтом.
5. Подтвердите разрешения Google.
6. Скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
7. Откройте `https://sosh20tver.ru/admin-changes.html`, вставьте этот URL и нажмите **Подключить**.

## 3. Если Apps Script уже был развернут раньше

После этого обновления нужно заменить **оба** файла в существующем проекте:

- `Code.gs`
- `Admin.html`

Затем:

1. **Развернуть → Управление развертываниями**.
2. Откройте текущее веб-приложение.
3. Нажмите **Изменить**.
4. Выберите **Новая версия**.
5. Сохраните развертывание.

URL останется прежним.

## 4. Основной режим: «Сетка учителей»

После входа по PIN:

1. Выберите дату.
2. Откроется сетка: строки — учителя, столбцы — уроки 1–12.
3. Исходное расписание берётся из технического листа `Учителя`, а предметы и кабинеты подставляются из основного листа `Расписание`.
4. Кликните по нужной клетке.

### Зачеркнуть старый урок

В окне клетки нажмите **Зачеркнуть**.

Клетка станет красной и перечёркнутой — это электронный аналог вашей отметки ручкой на бумаге.

Быстрая клавиша после выбора клетки: `X`.

### Поставить другой класс

1. Кликните по нужной клетке другого учителя.
2. Введите класс.
3. При необходимости укажите предмет и кабинет.
4. Нажмите **Сохранить**.

Новая клетка подсвечивается синим и получает метку **НОВОЕ**.

Если введён класс, который по основному расписанию уже имеет урок в этот номер, панель пытается подставить его текущий предмет и кабинет автоматически.

### Вернуть исходную клетку

Нажмите **Вернуть исходное** или клавишу `Delete`.

### Быстрый ввод с клавиатуры

После выбора клетки:

- `X` — зачеркнуть;
- `Delete` / `Backspace` — вернуть исходное;
- `Enter` — открыть редактор;
- если сразу начать вводить цифру/букву класса — откроется редактор с начатым вводом.

### Масштаб

Кнопки `−` и `+` меняют ширину клеток от 70% до 140%.

### Только изменённые строки

Флажок **Только изменённые строки** скрывает учителей, у которых на выбранную дату нет правок.

## 5. Как автоматически формируются изменения для учеников

Панель сравнивает:

**основное расписание класса → итоговую учительскую сетку после ваших правок**.

Примеры:

- урок был и после правок исчез → `отмена`;
- вместо истории поставили географию в 301 → `География (301)`;
- поменялся только учитель, но предмет и кабинет остались те же → ученикам ничего не показывается;
- изменился только кабинет → в ученический список попадёт новый вариант урока с кабинетом.

На вкладке **Список для учеников** видно, что именно будет опубликовано на сайте.

## 6. Ручная корректировка ученического списка

Автоматический список можно поправить перед публикацией:

- **Изменить** — переписать текст;
- **Не публиковать** — убрать конкретную автоматическую строку;
- **Добавить вручную** — добавить редкий случай, который нельзя вывести из сетки;
- **Сбросить ручные правки** — снова использовать чистый автоматический результат.

Это резервный режим; в обычной работе достаточно сетки учителей.

## 7. Публикация

Нажмите **Опубликовать изменения**.

Панель одновременно:

1. сохраняет правки учительской сетки в технический лист `Изменения_учителей`;
2. обновляет лист `Изменения`, который читает ученический сайт;
3. не затрагивает изменения других дат;
4. сообщает количество учительских и ученических изменений.

Технический лист `Изменения_учителей` создаётся автоматически при первом запуске панели и скрывается.

## 8. Печать замен

Кнопка **Печать замен** формирует компактный печатный лист:

- изменения по учителям;
- итоговые изменения для учеников.

Он рассчитан на обычную печать браузера и удобен как контрольный лист на день.

## 9. Сброс дня

Кнопка **Сбросить изменения дня** удаляет все текущие правки сетки и ручные корректировки в панели. До нажатия **Опубликовать** Google Таблица не меняется.

## 10. Защита

- вход по PIN;
- сессия до 6 часов с продлением при работе;
- предупреждение при попытке закрыть страницу с неопубликованными изменениями;
- Apps Script работает от имени владельца таблицы, поэтому ключи для записи не публикуются на GitHub Pages.

## 11. Важное про технический лист «Учителя»

Панель использует существующий лист `Учителя` как базовую привязку **учитель → урок → класс**. На публичном сайте этот лист не показывается.

Если основное учительское расписание когда-нибудь будет полностью заменено, нужно обновить лист `Учителя` одновременно с листом `Расписание`, после чего панель автоматически начнёт работать с новой базой.
