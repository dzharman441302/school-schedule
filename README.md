# МОУ СОШ № 20 г. Твери — расписание и изменения

Статический сайт на GitHub Pages (домен `sosh20tver.ru`). Данные берутся из Google Таблицы через Sheets API, изменения публикуются через панель на Google Apps Script. Сборка и установка библиотек не нужны.

## Страницы

| Страница | Для кого | Что показывает |
|---|---|---|
| `index.html` | ученики, родители | «Мой класс сегодня»: текущий урок, уроки дня, изменения; объявления школы |
| `schedule.html` | ученики, родители | неделя класса (таблица на компьютере, дни на телефоне), карточка «Сейчас», вкладка «Изменения», звонки |
| `staff.html` | учителя | сетка учителей с отменами, заменами и кабинетами; «мои настройки», персональная ссылка, печать |
| `tv.html` | ТВ в учительской | сетка «учитель × урок» на оставшиеся уроки дня: 10 учителей по алфавиту на странице (страницы «А–Д», «Е–Ме»…), смена каждые 15 секунд; сетка во всю ширину экрана, изменения дня отмечены цветом прямо в ней |
| `tv-students.html` | ТВ для учеников | табло параллели «класс × урок» с изменениями, параллели сменяются каждые 15 секунд; `?parallel=7` закрепляет параллель (10 и 11 показываются вместе) |
| `help.html` | учителя | заявка по ИКТ: «Техника не работает» или «Вопрос по программам», срочность, фото; вход по общему PIN сотрудников |
| `ikt.html` | зам по ИКТ | все заявки школы, фильтры, ответы, передача инженеру; вход по `IKT_PIN`; не в меню, не кэшируется |
| `help-qr.html` | зам по ИКТ | QR-наклейки на кабинеты, 12 на лист A4 |
| `achievements.html` | все | «Наши достижения»: итоги учебного года, разбивка по уровням, лента побед с фильтрами по параллели и направлению; имя ученика — только с согласия родителей |
| `achievements-form.html` | учителя | «Внести достижение»: мероприятие + ученики с результатами, фото дипломов, «Мои записи» (правка, пока не проверено); вход по личному PIN; не кэшируется |
| `achievements-review.html` | ответственный за олимпиады, администратор | очередь «На проверке», «Проверено» / «Вернуть» с комментарием, массовая отметка, реестр в Excel; у администратора — «Педагоги»: роли и PIN |
| `admin-changes.html` | администратор | обёртка панели внесения изменений (Apps Script) |
| `analytics/` | классные руководители | отчёт за триместр |

Старые адреса `classes.html`, `changes.html`, `news.html`, `vector20.html` перенаправляют на новые страницы.

Полезные адреса:
- `schedule.html?class=7А` — сразу расписание класса (кнопка «Ссылка на класс» копирует такую ссылку);
- `schedule.html#changes` — сразу вкладка изменений;
- `staff.html?teacher=Фамилия И.О.&mine=1` — персональная ссылка учителя (`&view=week` — сразу «Моя неделя»);
- `help.html?room=211` — форма заявки с подставленным кабинетом (адрес QR-наклейки);
- `ikt.html#0142` — сразу заявка № 0142.

## Файлы

- `config.js` — настройки школы, ссылки, ID таблицы, API-ключ, названия листов, список классов.
- `app.js` — ядро сайта: загрузка листов с кэшем, даты, учебный календарь (каникулы), общие функции.
- `schedule-core.js` — логика расписания: актуальный день с изменениями, текущий урок, карточка «Сейчас».
- `site-shell.js` — общее для страниц: нижнее меню на телефоне, «Ещё», установка приложения, состояние звонков в шапке, объявления, время публикации изменений.
- `schedule.js`, `home.js`, `staff.js` — страницы расписания, главная и учительская.
- `tv-core.js` — общее для ТВ-экранов: сцена 1920×1080, которая целиком масштабируется под любой телевизор, сверка часов с сервером сайта, шапка со звонками, смена страниц, подгонка длинного текста, отметка «Нет связи · данные от …».
- `tv.js`, `tv-students.js` — ТВ-экраны учительской и для учеников.
- `ict-core.js` — заявки по ИКТ: списки устройств и тем, кабинеты школы, подписи, вызов Apps Script; `help.js`, `ikt.js`, `help-qr.js` — страницы заявок; `qr.js` — встроенный генератор QR-кодов (без внешних библиотек).
- `achievements-core.js` — «Достижения»: запросы к API в Яндекс Облаке (`achievementsApi` в `config.js`), проверки формы, сжатие фото диплома; `achievements-form.js`, `achievements-review.js` — страницы. ФИО учеников не сохраняются в браузере. `achievements-public.js` — публичная часть (`achievementsPublicUrl`): «Наши достижения», блок «Поздравляем!» на главной, поздравления в бегущей строке ТВ; `achievements.js` — страница. Проверка: `node tests/achievements-core.js`, `node tests/achievements-public.js`.
- `subject-names.js` — расшифровка сокращений предметов («Вер» → «Вероятность и статистика»).
- `site.css` — единый стиль сайта; `tv.css` — стиль ТВ-экранов; `style.css` — старый стиль, страницами больше не подключается.
- `sw.js`, `manifest.webmanifest` — приложение для телефона (PWA).
- `assets/fonts/` — шрифт Onest (лицензия OFL); `assets/icons/` — сжатый логотип и иконки приложения.
- `apps-script/` — код панели изменений (копируется в проект Apps Script вручную).
- `max-worker/` — бот в MAX на Cloudflare Workers; `max-bot/` — тот же бот для своего сервера (Docker).
- `yc-achievements/` — «Достижения учащихся»: API в Яндекс Облаке (Python, YDB, Object Storage); ФИО учеников хранятся только там. Развёртывание и раздел о персональных данных — в `yc-achievements/README.md`. На сайте не публикуется.
- `tests/` — регрессионные тесты: `node tests/<файл>.js`.

## Листы Google Таблицы

Сайт читает листы `Расписание`, `Изменения`, `Учителя`, `Учителя_сайт`, `Статус_публикации`, `Оповещения`, `Настройки_сайта`. Их формат задаёт панель изменений — вручную менять заголовки не нужно.

### Новый необязательный лист `Календарь`

Позволяет сайту знать о каникулах и праздниках: такие дни пропускаются при выборе «ближайшего учебного дня» (изменения, карточка «Сейчас», сетка учителей).

| Дата начала | Дата окончания | Название |
|---|---|---|
| 26.10.2026 | 03.11.2026 | Осенние каникулы |
| 04.11.2026 | | День народного единства |

Если листа нет, учебными считаются все дни с понедельника по пятницу — как раньше. После создания листа сайт подхватит его в течение часа.

### Меню столовой: `data/menu-cycle.json`, лист `Меню_замены`

`data/menu-cycle.json` — 10-дневный цикл меню (завтрак и обед; у блюда короткое название, иконка, вес и калорийность). Файл собран из меню столовой и вручную не переписывается. День 1 — `cycleStart` (09.11.2026); дни цикла идут только по учебным дням — выходные, каникулы и праздники из листа `Календарь` пропускаются. Если столовая сбилась с цикла, в `Настройки_сайта` добавьте строку `menuCycleStart` с датой, которая была днём 1 — она важнее файла. Необязательный лист `Меню_замены`: `Дата | Приём пищи | Было | Стало` — замена блюда на один день (`Стало` пусто — блюдо убрано, `Было` пусто — добавлено). Логика — `menu-core.js`, проверка — `node tests/menu-core.js`.

### Слайд «Сегодня»: данные (`today-core.js`)

- **Погода** — Open-Meteo без ключа (координаты Твери в `config.js` → `today`), кэш 30 минут, без связи — последние данные до трёх часов; совет по восьми простым правилам («Скользко — не беги», «Не забудь зонт»…).
- **До каникул** — из листа `Календарь`: ближайшие записи со словом «каникул» в названии; «43 дня до зимних каникул», в последний учебный день «Завтра каникулы!», летом — «до лета N дней»; во время каникул блок не показывается.
- **Дежурство** — лист `Дежурство`: `Неделя с | Неделя по | Смена | Классы` (по строке на смену и неделю).
- **Самый пунктуальный класс** — по отметкам опозданий: самая длинная серия учебных дней без опозданий.
- **Бегущая строка** — объявления из `Оповещения` со значением «Всем», «Ученикам» или «Учителям» в столбце `На экран` (галочка в панели — следующий этап).
- **Праздник дня** — `data/days.json` (ключ `ММ-ДД`). **Это черновик: перед показом на экранах список должен проверить человек.** Пустой день — плашка не показывается.

- **«Сегодня в школе»** — только то, что администратор опубликовал в панели: «Ещё → Сегодня на ТВ: события и задача дня». До 5 событий на любую дату (время, что, где, «только для учителей»); «Сохранить черновик» — в закрытую таблицу, «Опубликовать» — в публичный лист `События_сайт` (`Дата | Время | Что | Где | Для | Опубликовано`), «Снять с публикации» — строки дня удаляются; после каждого действия есть «Вернуть». На экране — до 3 ближайших событий, прошедшие исчезают.
- **Задача дня** — там же в панели: задача, пояснение, параллели и правильный ответ (несколько вариантов через «;»). Текст задачи — в публичный лист `Задача_дня`, ответ — только в закрытую таблицу. Ученики отвечают на `task.html` (сюда ведёт QR): класс и ответ, без фамилий, один ответ с телефона в день. Ночью итоги дня выходят в `Задача_дня_итоги`: сколько верных, какой класс решил первым, ответ.
- Закрытая таблица для черновиков событий, ответов и ключей — «СОШ20 — служебная (закрытая)», скрипт создаёт её сам (свойство `PRIVATE_SPREADSHEET_ID`). Код — `apps-script/DayEvents.gs` и `apps-script/DayPanel.html`.
- В объявлениях панели появился выбор «Бегущая строка на ТВ» (столбец `На экран` листа `Оповещения`).

Проверка: `node tests/today-core.js`, `node tests/day-events.js`.

### Слайд «Сегодня» на экране для учеников (`tv-today.js`)

Шапка: часы и дата, текущий урок/перемена, «праздник дня». Ниже — меню (по времени: до конца 2-го урока «Сегодня на завтрак», с 3-го урока до 14:00 «Сегодня на обед», после 14:00 и в выходные «Завтра в меню», в каникулы «Приятного отдыха!») с шуточной подписью из `data/menu-phrases.json` (30 фраз, без повторов два учебных дня подряд), погода, «до каникул», дежурство и самый пунктуальный класс, «Сегодня в школе»; полоса «Задача дня» с QR на `task.html`; бегущая строка. Блок без данных не показывается — соседние растягиваются.

Ротация: на переменах «Сегодня» один раз за круг параллелей, в остальное время — после каждой параллели; когда уроков нет — только он. Длительность — 20 с (`config.js` → `today.slideSeconds`), табло — 15 с. На экране с `?parallel=N` слайда нет. Превью: `tv-students.html?slide=today&time=11:30&date=2026-11-23`.

**ТВ в учительской** (`tv.html`) показывает тот же слайд в учительском варианте: вместо «Задачи дня» — полоса «Сегодня по расписанию» (сколько изменений сегодня: отмен, замен, смен кабинета, сколько учителей затронуто; после 15:00 — сколько уже опубликовано на завтра), в дежурстве — дежурные администраторы обеих смен на сегодня (`config.js` → `lateness.duty`), в «Сегодня в школе» — и события «только для учителей», в бегущей строке — объявления «Всем» и «Учителям». Ротация: после каждого полного круга страниц сетки — «Сегодня» на 20 с; если страница одна, до 08:00 и после уроков — через раз; отдельная точка «Сегодня» в индикаторе страниц. Превью: `tv.html?slide=today&time=15:30&date=2026-11-23`.

Проверка: `node tests/tv-today.js`, `node tests/tv-rotation.js`.

### Необязательный лист `Помещения`

Помещения без уроков в расписании, на которые тоже можно подать заявку по ИКТ и напечатать QR-наклейку: первая колонка `Помещение` (например, `Библиотека`, `Медкабинет`, `Учительская`). Кабинеты из расписания добавлять не нужно — они берутся сами.

### Звонки: листы `Звонки` и `Звонки_даты`

Время уроков хранится в одном месте — его читают сайт, ТВ-экраны, бот MAX и панель. Листы создаёт панель при первом входе; заполнять их удобнее в панели: **Ещё → Расписание звонков**, а вариант на конкретный день выбирается рядом с датой («Звонки: Основное / Сокращённое»).

| Урок | Основное | Сокращённое |
|---|---|---|
| 1 | 08:00–08:40 | 08:00–08:30 |
| … | … | … |

`Звонки_даты`: `Дата | Вариант | Комментарий` — дни, когда действует не основной вариант. Вариант учитывается, только когда заполнены все 12 уроков. Без листов действует прежнее время звонков. Сайт подхватывает изменения в течение 10 минут, ТВ — в течение 10 минут, бот — сразу.

## Замер скорости

- **Сайт:** добавьте к адресу любой страницы `?debug=1` (например `staff.html?debug=1`). Внизу появится панель: когда данные получены и показаны, каждый запрос (лист Google, вызов Apps Script, файл), откуда (сеть / кэш), мс, КБ, строк. Кнопка «Копировать» — всё в буфер. Без `?debug=1` файл `perf.js` ничего не делает.
- **Панель завуча:** `admin-changes.html?debug=1` — внизу панели время каждого вызова сервера «туда-обратно».
- **Apps Script:** файл `Скорость.gs` (в проекте — `Скорость.js`, должен идти последним) записывает каждый вызов doGet / doPost / функций панели в скрытый лист `Замеры`: когда, действие, мс на сервере, строк прочитано, итог. Только время и количества. Записи копятся в свойствах скрипта и раз в 5 минут переносятся в лист триггером `perfFlush` (создаётся сам). Выключить: свойство скрипта `PERF_LOG` = `0`. Проверка: выполнить `perfStatus()` в редакторе — сколько функций под замером.

## Безопасность — сделать обязательно

1. **Ограничить API-ключ.** Google Cloud Console → APIs & Services → Credentials → ключ из `config.js`:
   - Application restrictions → *Websites*: `https://sosh20tver.ru/*`, `https://dzharman441302.github.io/*`;
   - API restrictions → только *Google Sheets API*.
2. **Закрыть служебные листы.** Скрытый лист Google Таблицы не защищён: пока таблица открыта по ссылке, любой может скачать любой её лист, включая `Отсутствия_учителей`, `Журнал_замен`, `Просмотры_учителей`. Надёжная схема:
   - создать отдельную «публичную» таблицу только с листами, которые читает сайт (`Расписание`, `Изменения`, `Учителя`, `Учителя_сайт`, `Статус_публикации`, `Оповещения`, `Настройки_сайта`, `Календарь`);
   - рабочую таблицу закрыть (доступ только сотрудникам);
   - в Apps Script при публикации копировать эти листы в публичную таблицу и указать её ID в `config.js`.
3. **PIN панели** — не короче 6 символов (свойство скрипта `ADMIN_PIN`). После 20 неверных попыток вход блокируется на 15 минут.
4. **Бот MAX через Apps Script** принимает сообщения только с секретом: задайте свойство `MAX_WEBHOOK_SECRET` и добавьте `?secret=...` к адресу вебхука. Без свойства такие сообщения игнорируются.
