# МОУ СОШ № 20 г. Твери — расписание и изменения

Статический сайт на GitHub Pages (домен `sosh20tver.ru`). Данные берутся из Google Таблицы через Sheets API, изменения публикуются через панель на Google Apps Script. Сборка и установка библиотек не нужны.

## Страницы

| Страница | Для кого | Что показывает |
|---|---|---|
| `index.html` | ученики, родители | «Мой класс сегодня»: текущий урок, уроки дня, изменения; объявления школы |
| `schedule.html` | ученики, родители | неделя класса (таблица на компьютере, дни на телефоне), карточка «Сейчас», вкладка «Изменения», звонки |
| `staff.html` | учителя | сетка учителей с отменами, заменами и кабинетами; «мои настройки», персональная ссылка, печать |
| `tv.html` | ТВ в учительской | карточки учителей, по две на экран, страницы сменяются каждые 8 секунд |
| `tv-students.html` | ТВ для учеников | классы одной параллели, параллели сменяются каждые 15 секунд; `?parallel=7` закрепляет параллель |
| `admin-changes.html` | администратор | обёртка панели внесения изменений (Apps Script) |
| `analytics/` | классные руководители | отчёт за триместр |

Старые адреса `classes.html`, `changes.html`, `news.html`, `vector20.html` перенаправляют на новые страницы.

Полезные адреса:
- `schedule.html?class=7А` — сразу расписание класса (кнопка «Ссылка на класс» копирует такую ссылку);
- `schedule.html#changes` — сразу вкладка изменений;
- `staff.html?teacher=Фамилия И.О.&mine=1` — персональная ссылка учителя.

## Файлы

- `config.js` — настройки школы, ссылки, ID таблицы, API-ключ, названия листов, список классов.
- `app.js` — ядро сайта: загрузка листов с кэшем, даты, учебный календарь (каникулы), общие функции.
- `schedule-core.js` — логика расписания: актуальный день с изменениями, текущий урок, карточка «Сейчас».
- `site-shell.js` — общее для страниц: нижнее меню на телефоне, «Ещё», установка приложения, состояние звонков в шапке, объявления, время публикации изменений.
- `schedule.js`, `home.js`, `staff.js` — страницы расписания, главная и учительская.
- `tv.js`, `tv-students.js` — ТВ-экраны.
- `subject-names.js` — расшифровка сокращений предметов («Вер» → «Вероятность и статистика»).
- `site.css` — единый стиль сайта; `tv.css` — стиль ТВ-экранов; `style.css` — только для старых служебных страниц (`admin-changes.html`, `post.html`).
- `sw.js`, `manifest.webmanifest` — приложение для телефона (PWA).
- `assets/fonts/` — шрифт Onest (лицензия OFL); `assets/icons/` — сжатый логотип и иконки приложения.
- `apps-script/` — код панели изменений (копируется в проект Apps Script вручную).
- `max-worker/` — бот в MAX на Cloudflare Workers; `max-bot/` — тот же бот для своего сервера (Docker).
- `tests/` — регрессионные тесты: `node tests/<файл>.js`.

## Листы Google Таблицы

Сайт читает листы `Расписание`, `Изменения`, `Учителя`, `Учителя_сайт`, `Статус_публикации`, `Оповещения`, `Настройки_сайта`. Их формат задаёт панель изменений — вручную менять заголовки не нужно.

### Новый необязательный лист `Календарь`

Позволяет сайту знать о каникулах и праздниках: такие дни пропускаются при выборе «ближайшего учебного дня» (изменения, карточка «Сейчас», сетка учителей).

| Дата начала | Дата окончания | Название |
|---|---|---|
| 26.10.2026 | 03.11.2026 | Осенние каникулы |
| 04.11.2026 | | День народного единства |

Если листа нет, учебными считаются все дни с понедельника по пятницу — как раньше. После создания листа сайт подхватит его в течение часа.

## Публикация

1. Внесите изменения, проверьте тесты: `node tests/schedule-regression.js`, `node tests/schedule-weekly-review.js`, `node tests/schedule-workspace.js`, `node tests/tv-rotation.js`.
2. `git push` в ветку `main` — GitHub Pages обновит сайт за 1–2 минуты.
3. Изменения в `apps-script/` отдельно перенесите в проект Apps Script «СОШ 20 — панель изменений» и выпустите новую версию рабочего развертывания (адрес панели не меняется). Вручную: вставить файлы в редактор → «Развернуть → Управление развертываниями → Изменить → Новая версия». Или через [clasp](https://github.com/google/clasp):
   ```
   clasp clone 1MlwQ3FlZhmsFTecQqSlP6P3vpNx8dfazEidUjlJMkDkUXDZwJ3Z_WHx1
   ```
   скопировать изменённые файлы под именами проекта (`Code.gs` → `Код.js`, `ScheduleModel.gs` → `SheduleModel.js`, остальные `.gs` → `.js`), затем `clasp push`, `clasp create-version "описание"` и `clasp update-deployment AKfycbwLKHUH2tnJ845I5uQ8r1_PAe1svBx462EUcwpz7ex7P93wHhX0WM2RkPpPnlrIlvsglQ -V <номер версии>`.

Номер версии файлов в HTML (`?v=18`) и `CACHE` в `sw.js` увеличивайте при изменении CSS/JS, чтобы телефоны получили новую версию.

## Безопасность — сделать обязательно

1. **Ограничить API-ключ.** Google Cloud Console → APIs & Services → Credentials → ключ из `config.js`:
   - Application restrictions → *Websites*: `https://sosh20tver.ru/*`, `https://dzharman441302.github.io/*`;
   - API restrictions → только *Google Sheets API*.
2. **Закрыть служебные листы.** Скрытый лист Google Таблицы не защищён: пока таблица открыта по ссылке, любой может скачать любой её лист, включая `Отсутствия_учителей`, `Журнал_замен`, `Просмотры_учителей`. Надёжная схема:
   - создать отдельную «публичную» таблицу только с листами, которые читает сайт (`Расписание`, `Изменения`, `Учителя`, `Учителя_сайт`, `Статус_публикации`, `Оповещения`, `Настройки_сайта`, `Календарь`);
   - рабочую таблицу закрыть (доступ только сотрудникам);
   - в Apps Script при публикации копировать эти листы в публичную таблицу и указать её ID в `config.js`.
3. **PIN панели** — не короче 6 символов (свойство скрипта `ADMIN_PIN`). После 20 неверных попыток вход блокируется на 15 минут.
4. **Бот MAX через Apps Script** принимает сообщения только с секретом: задайте свойство `MAX_WEBHOOK_SECRET` и добавьте `?secret=...` к адресу вебхука. Без свойства такие сообщения игнорируются.
