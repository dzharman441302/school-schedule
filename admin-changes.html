Панель изменений

Изменения вносятся прямо в учительскую сетку. После публикации автоматически обновляются список для учеников, сетка учителей и архив.

Закрытая страница

Первичная настройка

Панель на сайте готова. Один раз подключите защищённый Google Apps Script.

  1. Обновите Apps Script по инструкции FEATURES_GUIDE.md.
  2. Разверните его как веб-приложение.
  3. Вставьте полученный адрес ниже. Он сохранится только в этом браузере.

Сетка учителей → проверка → изменения детям → публикация / отложенная публикация → архив.
