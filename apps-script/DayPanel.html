Сегодня на ТВ

События дня и задача дня для слайда «Сегодня» на экранах. На экраны попадает только опубликованное.

«Сегодня в школе»

До 5 событий: время, что и где. Ученики видят на экране до трёх ближайших, прошедшие исчезают сами. «Только для учителей» — педсовет, совещание, МО: такое событие покажет только ТВ в учительской.

Задача дня

Задача появляется на экране с QR-кодом; ученики отвечают на странице task.html, без фамилий — только класс. Правильный ответ виден только здесь; на экран он выходит на следующий день вместе с итогами. Несколько верных вариантов — через «;», например «12; двенадцать».
