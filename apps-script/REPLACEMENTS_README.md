# Замены и объединение двух классов — обновление 25.09.2026

## Установка в действующий проект Google Apps Script

Перед заменой сохраните копию текущих четырёх файлов Apps Script. Рабочую Google-таблицу, её ID, PIN и свойства скрипта менять не нужно.

1. Полностью замените содержимое существующих файлов `Code.gs`, `Admin.html`, `PublishWarnings.gs`, `ManagementExtensions.gs` файлами из этого пакета.
2. Создайте два новых файла типа «Скрипт»: `ScheduleModel.gs`, `ReplacementJournal.gs` и вставьте их содержимое.
3. Создайте файл типа «HTML» с именем `ReplacementPanel` и вставьте содержимое `ReplacementPanel.html`.
4. Сохраните проект. Откройте «Развернуть» → «Управление развертываниями», выберите действующее веб-приложение, нажмите карандаш, выберите «Новая версия», затем «Развернуть». Существующие URL и настройки доступа оставьте прежними.
5. Перезагрузите панель. В верхней строке появится кнопка «Замены». Новые служебные листы создаются автоматически при первом обращении к журналу; отдельно запускать функцию установки не требуется.

Все семь файлов должны быть установлены вместе. Обновление файлов в GitHub само по себе не обновляет версию веб-приложения Google Apps Script. Изменённые публичные `staff.js`, `tv.js`, стили и ссылки на них публикуются отдельно через GitHub Pages.

## Подтверждение после публикации

После успешной публикации появляется окно «Замены и учёт часов». Для каждой записи предусмотрены «Проверить», «Учесть», «Не учитывать», число часов, заменяемый учитель и пояснение.

Сначала все новые записи имеют статус «Проверить» и дают ноль подтверждённых часов. «Применить рекомендации» заполняет только форму, а не журнал. Решения записываются кнопкой «Сохранить решения». Можно закрыть окно и вернуться позже; счётчик показывает ожидающие решения за месяц выбранного дня.

Обычный перенос своего урока и смена кабинета рекомендуются к исключению. Подгруппы сопоставляются с выбывшими учителями, а не с последней фамилией класса. Объединённые занятия, неоднозначные группы и расхождения с ручными изменениями учеников требуют отдельного решения. Для нестандартного подтверждения обязательно пояснение. Отменённый урок нельзя подтвердить как проведённый.

Это инструмент фиксации решений администратора, а не доказательство фактического проведения занятия или автоматический расчёт оплаты. Рекомендации по переносам используют изменения внутри одного дня; междневные переносы и нестандартные договорённости проверяются вручную.

## Два класса одному учителю

Откройте клетку учителя, заполните «Класс» и «Второй класс (необязательно)», укажите общий предмет и кабинет, сохраните. Например: `5А` и `5Б`. В учительской сетке будет `5А + 5Б`, у учеников изменения формируются отдельно для каждого класса. В клетке сохраняется одно общее занятие; два разных предмета или два разных кабинета в ней не задаются.

Если второй класс забирается у другого преподавателя, снимите или измените исходное назначение этого преподавателя. Иначе проверка покажет одновременное назначение класса нескольким учителям. Само заполнение второго класса не удаляет чужой урок автоматически.

Один учитель и один номер урока — одна запись учёта независимо от числа классов. По умолчанию предлагается один час, но он не подтверждается автоматически. Явное решение о 1,5 или 2 часах допускается только для объединения двух классов и с обязательным пояснением; применимость такого учёта определяет администратор.

## Журнал, сводка, восстановление

«Журнал»: период, учитель, статус, детали, CSV только подтверждённых записей и печать. «Сводка часов»: сумма только подтверждённых часов, а не количество строк/классов. «История решений»: прежнее и новое решение по дню.

Для пропущенных сентябрьских дней выберите период, например `01.09.2026` — `25.09.2026`, и «Восстановить период». За один запуск — максимум 31 день. Уже восстановленные готовые дни повторно не создаются. Расписание и опубликованные замены не перепубликуются. Предпочтение отдаётся сохранённой исходной/итоговой сетке «Учителя_сайт». Если её нет, используется архив правок с текущим основным расписанием, с отдельной пометкой необходимости сверки. Восстановленные часы всегда ожидают решения; прежние 112 автоматически рассчитанных часов не утверждаются.

Старые девятиколоночные строки «Журнал_замен» сохраняются как неподтверждённое наследие и не суммируются с новым учётом. Ручную запись можно добавить с пояснением, после чего указать заменяемого учителя и подтвердить. Дубли одного учителя на одном уроке запрещены.

## Повторная публикация и сбои

Неизменённые записи сохраняют решение. При изменении назначения запись сбрасывается на проверку. Удалённые замены помечаются неактуальными и исключаются из суммы, история сохраняется. Отложенная публикация записывает ожидание проверки; оно доступно при следующем открытии панели. Откат тоже обновляет учёт. Защита по версии публикации и версии решений не позволяет старой вкладке молча перезаписать новое решение.

При незавершённой записи публикации или решения день не входит в итог. Панель сообщает о необходимости повторного открытия/проверки. Учёт не зависит от последующего редактирования основного расписания: при публикации сохраняется снимок исходной и итоговой сетки.

Новые служебные листы: «Замены_публикации», «Замены_аудит»; «Журнал_замен» расширяется с сохранением первых девяти колонок. Не удаляйте их. Скрытие листа не является ограничением доступа: права определяются настройками Google-таблицы. В журнале используется общий администратор панели, поскольку общий PIN не позволяет различать конкретных сотрудников.

33 автоматических проверки на модельной Google-таблице: назначения, подгруппы, переносы, повторная публикация, отмены, откат, очередь отложенных публикаций, подтверждение, восстановление, прерванная запись, права сессии, синтаксис.

Интерфейс проверен в Chromium с локальной моделью серверных вызовов: назначение двух классов, публикация и автоматическое открытие окна, сохранение одного часа, CSV, сброс решения после изменения, ручная запись, экран телефона, учительская сетка и ТВ. Реальный развернутый Apps Script этой проверкой не подменяется: после установки проверьте один рабочий день и сверьте результат.
