# Компактная панель: ноутбук и телефон

Обновление 03.10.2026. Основа — согласованный макет с белой сеткой, синим акцентом, редактором под строкой и отдельным мобильным представлением. Все значения на реальном сайте берутся из прежней таблицы, демонстрационные имена и даты макета не добавляются.

## Установка одним пакетом

1. Сохраните текущие файлы **живого проекта Apps Script** отдельно. Папка `backup/2026-10-03-before-ui` в GitHub содержит полный снимок **исходников репозитория** до редизайна, но не данные Google-таблицы и не неизвестную версию развертывания.
2. В существующем Apps Script полностью замените семь файлов: `Admin.html`, `Code.gs`, `PublishWarnings.gs`, `ManagementExtensions.gs`, `ScheduleModel.gs`, `ReplacementJournal.gs`, `ReplacementPanel.html`.
3. Добавьте HTML-файл **WorkspaceStyles** и вставьте содержимое `WorkspaceStyles.html`. Расширение `.html` редактор добавляет автоматически.
4. Сохраните. «Развернуть» → «Управление развертываниями» → существующее развертывание → карандаш → «Новая версия» → «Развернуть».
5. Обновите страницу панели. PIN, `SPREADSHEET_ID`, прочие свойства и прежний URL менять не требуется. Отдельно устанавливать старое обновление недельного журнала не нужно: оно включено.

Устанавливайте все восемь файлов вместе. GitHub Pages обновляет публичные страницы, но не опубликованную версию Apps Script.

## Ноутбук

Верхние строки: дата, статус, «Сохранить черновик», «Опубликовать», поиск, фильтры, отмена/возврат, плотность. Все 12 уроков видны по ширине при 1366 px; длинные предметы переносятся без сокращения данных. Столбец учителя и номера уроков закреплены. Редактор раскрывается под выбранной строкой, другие назначения остаются на экране.

«Ещё» содержит печать для учителей и учеников, архив, отложенную публикацию, свободные кабинеты, объявления, распознавание фото и другие прежние инструменты. Новые разделы «Календарь» и «Отчёты» из иллюстрации не создаются фиктивно.

«Снят» означает отменённое назначение в сетке, а не час для оплаты. Предмет остаётся читаемым, без перечёркивания. Статусы «Изменён», «Новый», «Кабинет» выделены цветом и текстом.

## Телефон

Нижние переключатели «Учителя» и «По уроку». В первом режиме — уроки выбранного учителя; во втором — назначения на выбранный номер урока, с фильтром свободных учителей. «Ещё → Обзор всей сетки» сохраняет доступ к общей таблице. Редактор занимает экран, поддерживает второй класс, кабинет, предмет и примечание. Сохранение клетки изменяет только черновик; публикация выполняется отдельно после предпросмотра.

## Предпросмотр учеников и ручные исключения

Отдельная вкладка «Изменения для учеников» убрана из основной навигации. Перед публикацией показывается готовый результат для затронутых классов; есть отдельный просмотр класса. Генерация из сетки учителей сохранена.

Ранее введённые ручные исключения не удаляются. Они доступны через «Ещё → Ручные исключения ученикам». При последующем редактировании назначения в учительской сетке ручное исключение снимается только для затронутого класса/урока; остальные сохраняются. В предпросмотре такие записи помечены отдельно. Не меняйте старые исключения без проверки.

## Черновики и безопасность даты

Изменённая сетка автоматически сохраняется **в этом браузере на этом устройстве**. После возврата предлагается восстановить её; данные опубликованного сайта от этого не меняются. Кнопка «Сохранить черновик» записывает копию в существующий серверный лист `Черновики_дней`; загрузить её можно через «Ещё». Общий серверный черновик дня один, поэтому при работе нескольких администраторов координируйте его сохранение.

Черновик локального браузера не равен серверному и не является независимой резервной копией всей системы. Режим приватного просмотра или очистка данных браузера могут удалить локальные черновики. При невозможности локального сохранения панель сообщает об этом.

При отказе от смены даты поле возвращается к дате загруженной сетки. Во время загрузки/публикации редактирование блокируется. Изменения в открытой форме не теряются при переходе через мобильную ширину. Отправка происходит для даты загруженного дня, а не случайно изменённого поля.

Публикация из новой панели проверяет версию сетки. Если другой оператор уже опубликовал этот день или поменял основу, устаревшая вкладка получит отказ вместо перезаписи. Старые интерфейсы/прямые вызовы без номера версии остаются совместимыми, поэтому для этой защиты обновите используемую панель на всех устройствах.

## Журнал замен — прежние правила сохранены

Включено недельное обновление 01.10.2026: только переданные другому учителю уроки, без простых отмен, смен кабинета и собственных переносов. После ежедневной публикации окно не открывается. С пятницы есть неблокирующее напоминание в открытой панели. Просмотр всей недели, подтверждения, фильтры, CSV, сводка и аудит сохранены. CSV — действующая выгрузка, не новый формат XLSX.

Одно назначение двух классов не удваивает часы автоматически. Факт проведения/учёта подтверждает администратор. Данные журнала и основного расписания при установке не заменяются демонстрационными.

## Публичные страницы

Номер урока больше не содержит узкую строку времени: диапазон времени размещён под предметом рядом с кабинетом. Отменённые уроки читаются без перечёркивания. Общий разбор названий не принимает `(технология)` за кабинет. Сетка сотрудников использует ту же иерархию. В ТВ меняется только оформление прежнего значения, а порядок, интервалы и исправленная прокрутка всех страниц сохраняются.

## Проверка и границы

Автотесты: `node tests/schedule-regression.js`, `node tests/schedule-weekly-review.js`, `node tests/schedule-workspace.js`, `node tests/tv-rotation.js`.

Вёрстка/взаимодействия проверены в Chromium на локальном HTML с моделью Google Sheets/RPC: 1366×768, 1440×900, 390×844, ТВ 1920×1080. Browser plugin отсутствует; использован Playwright. Среда не разрешает браузеру открывать localhost, поэтому HTML и зависимости встроены в офлайн-страницу; серверная логика исполнялась в памяти, не в живой таблице. Визуально сверены сетка, иерархия текста, статусы, строковый редактор, мобильная форма и время у учеников. Подставлен рабочий формат дат вместо ошибочной даты иллюстрации. Совпадение до пикселя и поведение реального iframe/авторизации Google этим тестом не подтверждаются.

После установки в Google Apps Script проверьте вход, один черновик и предпросмотр на ноутбуке/телефоне, затем одну согласованную рабочую публикацию. Загрузки вложений, реальная отправка уведомлений и OCR на живом сервисе этой UI-проверкой не запускались.
