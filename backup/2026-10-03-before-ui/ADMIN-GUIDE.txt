МОУ СОШ № 20 г. Твери — как обновлять данные сайта

1. РАСПИСАНИЕ

Рабочий лист Google Таблицы должен называться точно «Расписание».
Первая строка:
Класс | Урок | ПН | ВТ | СР | ЧТ | ПТ

После сохранения изменений просто откройте страницу расписания заново.
Сайт запрашивает свежие данные при каждом открытии. Кнопка «Обновить»
также принудительно перечитывает таблицу.

2. ИЗМЕНЕНИЯ

Рабочий лист должен называться точно «Изменения».
Первая строка:
Дата | Класс | Урок | Изменения | Примечание

Сайт показывает только текущий и следующий учебный день.
В субботу и воскресенье выводятся понедельник и вторник.
Записи с прошедшими или более поздними датами остаются в таблице,
но в блок ближайших изменений не попадают.

Рекомендуемый формат даты: ДД.ММ.ГГГГ, например 05.09.2026.

3. ДОКУМЕНТЫ БЕЗ ПРАВКИ GITHUB

В той же Google Таблице создайте лист «Документы».
Первая строка:
Категория | Название | Описание | Ссылка | Тип | Имя файла | Статус | Порядок

Порядок действий:
1) загрузите файл в Google Drive;
2) включите «Все, у кого есть ссылка» → «Читатель»;
3) скопируйте ссылку;
4) добавьте строку в лист «Документы»;
5) укажите статус «опубликовано»;
6) в «Порядок» укажите число: чем оно меньше, тем выше документ.

Сам файл хранится на Google Drive. Таблица хранит только описание и ссылку.

4. БЕЗОПАСНОСТЬ

Основную таблицу сайта также следует открывать только в режиме
«Все, у кого есть ссылка» → «Читатель». Не используйте публичный режим
«Редактор»: в нём любой человек по ссылке может изменить расписание.

5. ПУБЛИКАЦИЯ НОВОЙ ВЕРСИИ САЙТА

Скопируйте содержимое комплекта в корень репозитория с заменой,
не удаляйте CNAME, выполните commit и push в ветку GitHub Pages.
После публикации откройте сайт с Ctrl+F5 или в приватном окне.
