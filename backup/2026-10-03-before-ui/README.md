# МОУ СОШ № 20 г. Твери — сайт расписания, «Вектора 20», новостей и документов

Готовый статический сайт для GitHub Pages. Сервер, база данных, сборка и установка библиотек не требуются. Содержимое папки размещается в корне действующего репозитория.

Сайт является информационным ресурсом для учеников, родителей и педагогов. На страницах нет заявления о том, что данный ресурс является официальным сайтом образовательной организации. Отдельная кнопка ведёт на официальную страницу школы в региональной системе.

## Структура сайта

В интерфейсе оставлены три основных раздела:

1. **Расписание** — расписание классов, изменения на два ближайших учебных дня и расписание звонков.
2. **Вектор 20** — система выявления и поддержки интересов, исследований, проектов и олимпиадных проб.
3. **Новости и документы** — школьные новости с фотографиями, важные объявления, общешкольные документы и полный комплект материалов «Вектора 20».

Расписание учителей из интерфейса удалено. Старый адрес `teachers.html` перенаправляет посетителя на расписание классов, а `changes.html` — на вкладку изменений.

# 1. Настройки `config.js`

## Контактная кнопка

Сейчас кнопка «Связаться со школой» ведёт в сообщения паблика ВК:

```js
links: {
  contactUrl: 'https://vk.me/school_20_tver',
  officialSite: 'https://school.tver.ru/school/20',
  vkCommunity: 'https://vk.ru/school_20_tver'
}
```

Чтобы кнопка вела лично на ответственного сотрудника, замените только значение `contactUrl`. Подойдёт ссылка на личную страницу ВК, диалог, форму обратной связи или другой публичный канал.

## «Вектор 20»

После создания отдельной формы самовыдвижения можно заполнить:

```js
vector20: {
  coordinator: 'Фамилия Имя Отчество',
  contactEmail: 'mail@example.ru',
  applicationUrl: 'https://forms.gle/...'
}
```

Кнопки вступления на странице «Вектор 20» начнут открывать эту форму. Пока поле пустое, используется общая контактная ссылка.

# 2. Рекомендуемая модель публикации новостей

Для текущего масштаба оптимальна связка:

- **Google Таблица** — текст, дата, категория, статус и ссылки;
- **публичная папка Google Drive** — фотографии и документы;
- **GitHub Pages** — сам сайт.

Это сохраняет привычный способ работы: новость добавляется строкой в таблицу, а код сайта менять не требуется.

## Лист `Новости`

Рекомендуемая первая строка:

```text
ID | Дата | Категория | Заголовок | Анонс | Текст | Фото | Подпись фото | Ссылка | Текст ссылки | Закрепить | Статус
```

Пример:

| ID | Дата | Категория | Заголовок | Анонс | Текст | Фото | Подпись фото | Ссылка | Текст ссылки | Закрепить | Статус |
|---|---|---|---|---|---|---|---|---|---|---|---|
| science-week-2026 | 05.09.2026 | События | В школе открылась Неделя науки | Первые мастерские уже начали работу | Полный текст новости. Абзацы можно разделять переносами строки. | https://drive.google.com/file/d/FILE_ID/view | Участники первой мастерской | https://... | Подробнее | да | опубликовано |

### Назначение столбцов

- `ID` — стабильный короткий идентификатор латиницей, например `science-week-2026`. После публикации его лучше не менять: он входит в адрес страницы новости.
- `Дата` — `05.09.2026`, `05/09/2026`, `2026-09-05` или дата Google Sheets.
- `Категория` — например `События`, `Объявления`, `Вектор 20`, `Спорт`, `Достижения`.
- `Заголовок` — название новости.
- `Анонс` — короткий текст для карточки. Если поле пустое, сайт сформирует сокращение из полного текста.
- `Текст` — полный материал. Обычные переносы строки превращаются в абзацы.
- `Фото` — одна или несколько ссылок на изображения.
- `Подпись фото` — общий альтернативный текст для изображений.
- `Ссылка` — необязательная внешняя ссылка: регистрация, положение, форма, публикация ВК и т. п.
- `Текст ссылки` — подпись кнопки.
- `Закрепить` — `да`, `true`, `1` или `+`. Закреплённые записи выводятся первыми.
- `Статус` — `опубликовано`, `черновик` или `архив`. Черновики и архивные записи не показываются.

## Несколько фотографий

В одной ячейке столбца `Фото` укажите ссылки:

- через точку с запятой;
- либо каждую с новой строки.

Первая фотография используется как обложка, остальные выводятся галереей на странице новости.

Пример:

```text
https://drive.google.com/file/d/FILE_ID_1/view;
https://drive.google.com/file/d/FILE_ID_2/view;
https://drive.google.com/file/d/FILE_ID_3/view
```

## Фотографии через Google Drive

1. Создайте отдельную папку, например `Фото для сайта школы`.
2. Для папки или каждого файла включите доступ **«Все, у кого есть ссылка»**.
3. Скопируйте обычную ссылку вида:

```text
https://drive.google.com/file/d/FILE_ID/view?usp=sharing
```

4. Вставьте её в столбец `Фото`.

Сайт автоматически преобразует публичную ссылку Google Drive в адрес изображения. Если доступ к файлу закрыт, вместо него появится нейтральная заглушка.

### Важное ограничение

Не публикуйте фотографии детей без предусмотренных школой согласий на обработку и распространение изображения. Публичная ссылка на Google Drive фактически делает файл доступным всем посетителям сайта.

## Локальные фотографии

Фотографии можно хранить непосредственно в репозитории:

1. положите файл в `assets/news/`, например `science-week-01.jpg`;
2. в таблице укажите:

```text
assets/news/science-week-01.jpg
```

Преимущество — стабильная загрузка без внешнего сервиса. Недостаток — для каждой новой фотографии нужен commit в GitHub.

## Совместимость с листом `Объявления`

Сайт сначала пытается загрузить лист `Новости`. Если его нет или он пуст, автоматически используется существующий лист `Объявления`.

Поддерживаются простые варианты:

```text
Заголовок | Текст
```

и

```text
Заголовок | Текст | Дата | Тип | Ссылка
```

Поэтому переход на расширенную модель можно сделать постепенно, не ломая действующие объявления.

# 3. Google Таблица

## Лист `Расписание`

Рекомендуемая первая строка:

```text
Класс | Урок | ПН | ВТ | СР | ЧТ | ПТ
```

Пример:

| Класс | Урок | ПН | ВТ | СР | ЧТ | ПТ |
|---|---:|---|---|---|---|---|
| 7А | 1 | Русский язык | Математика | История | Информатика | Физика |

Допускаются полные названия дней недели. Столбец `СБ` поддерживается, если школа использует шестидневную учебную неделю.

## Лист `Изменения`

Рекомендуемая первая строка:

```text
Дата | Класс | Урок | Изменения | Примечание
```

Пример:

| Дата | Класс | Урок | Изменения | Примечание |
|---|---|---:|---|---|
| 31.07.2026 | 7А | 3 | Математика вместо физики | кабинет 21 |

Поддерживаются даты `31.07.2026`, `31/07/2026`, `31-07-2026` и `2026-07-31`.

### Логика учебных дней

Изменения показываются для двух ближайших учебных дней:

- в пятницу — пятница и понедельник;
- в субботу — понедельник и вторник;
- в воскресенье — понедельник и вторник.

Суббота и воскресенье не попадают в окно изменений. Это не влияет на возможность хранить субботнее основное расписание при шестидневной неделе: правило относится именно к блоку ближайших изменений по текущему техническому заданию.

## Лист `Важное`

Необязательный лист. При его отсутствии используются резервные карточки из `content.js`.

```text
Метка | Заголовок | Текст | Ссылка | Текст ссылки | Статус | Порядок
```

- `Статус`: `опубликовано`, `черновик`, `архив`;
- `Порядок`: число, определяющее очередность карточек.

## Лист `Документы`

Необязательный лист для общешкольных документов:

```text
Категория | Название | Описание | Ссылка | Тип | Имя файла | Статус | Порядок
```

Пример:

| Категория | Название | Описание | Ссылка | Тип | Имя файла | Статус | Порядок |
|---|---|---|---|---|---|---|---:|
| Учебный процесс | Календарный учебный график | Актуальная версия | https://... | PDF | | опубликовано | 10 |

Ссылка может вести на Google Drive, официальный ресурс или локальный файл сайта. Черновики и архивные записи скрываются.

## Лист `Возможности`

Необязательный лист для банка «Вектора 20»:

```text
Название | Направление | Классы | Срок | Формат | Категория | Приоритет | Описание | Ссылка | Статус
```

- `Направление`: `Исследую`, `Проектирую`, `Решаю`, `Объясняю`;
- `Категория`: `A`, `B` или `C`;
- `Приоритет`: `P1`, `P2`, `P3` или `P4`;
- `Статус`: `актуально`, `архив`, `закрыто`, `неактуально`.

На публичной странице выводятся только актуальные записи категорий A и B.

# 4. Кэш и отказоустойчивость

Сайт обращается к Google Sheets API из браузера и сохраняет успешные ответы локально:

- свежий кэш используется около 10 минут;
- при кратковременном сетевом сбое может быть показана последняя сохранённая версия;
- пользователь может нажать «Обновить» в разделе расписания;
- отсутствие необязательного листа не ломает страницу: используются резервные данные или понятное пустое состояние.

# 5. Публикация на GitHub Pages

1. Сделайте резервную копию действующего репозитория.
2. Скопируйте **всё содержимое** этой папки в корень репозитория с заменой файлов.
3. Проверьте `config.js` — ID таблицы, API-ключ и контактную ссылку.
4. Не удаляйте `CNAME`, если используется домен `sosh20tver.ru`.
5. Выполните commit и push в ветку, из которой публикуется GitHub Pages.
6. После обновления откройте сайт с `Ctrl+F5` или в режиме инкогнито.

# 6. Проверка после публикации

- главная страница открывается без горизонтальной прокрутки;
- мобильное меню работает на ширине 320–480 px;
- кнопка «Связаться со школой» ведёт по нужному адресу;
- ссылки на официальную страницу и ВК открываются;
- список классов загружается;
- выбранный класс сохраняется;
- вкладка изменений открывается по `classes.html#changes`;
- переход пятница → понедельник работает;
- `teachers.html` и `changes.html` корректно перенаправляют;
- новости открываются отдельными страницами;
- фотографии из Drive доступны без авторизации;
- фильтры и поиск работают в новостях и документах;
- файлы «Вектора 20» скачиваются;
- страницы проверены на смартфоне и компьютере.

# 7. Безопасность и приватность

API-ключ Google Sheets виден в клиентском JavaScript. В Google Cloud Console его необходимо ограничить:

- разрешить только **Google Sheets API**;
- разрешить HTTP referrers только для `https://sosh20tver.ru/*` и фактического адреса GitHub Pages.

Удаление расписания учителей из меню не закрывает данные автоматически. Если лист `Учителя` остаётся в той же публично читаемой таблице, его технически можно запросить напрямую. Надёжная схема:

1. создать отдельную публичную Google Таблицу для сайта;
2. перенести в неё только листы `Расписание`, `Изменения`, `Новости`, `Объявления`, `Важное`, `Документы`, `Возможности`;
3. оставить расписание учителей в закрытой внутренней таблице;
4. указать в `config.js` ID публичной таблицы.
